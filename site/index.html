电脑配件价格数据

图吧工具箱「电脑配件价格走势」插件的公开数据源。

数据文件：data/latest.json

更新频率：每 8 小时由 GitHub Actions 自动抓取一次。

数据来源：VRAMGlass（vramglass.com） 闲鱼市场在售挂单的中位价、Q1/Q3 区间与挂单数，历史最多 365 天。

全品类参考价：data/catalog.json

来自中关村在线公开产品信息；参考标价和关注热度不等于真实购物成交价。

电商公开标价：data/market.json（须配置合法授权 API 后才可生成）

逐 SKU 保留来源、采样时间、商品链接和价格类型。首次开通前此链接可能不存在。

声明

本仓库定时保存 VRAMGlass、ZOL 与未来获授权的电商公开报价；闲鱼挂单价、ZOL 参考价、电商公开标价是不同统计口径。 数据仅供研究参考，不构成交易建议。图吧工具箱与上述平台无隶属关系。

如数据提供方希望停止镜像，请在本仓库提交 Issue，我们会立即下线相关数据。

插件包内还附带一份打包时的数据快照（seed），离线时也能看到最近一次行情。
